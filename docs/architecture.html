What happens when you say "remember Sarah's birthday is March 14"

  1. When the chat starts, Claude connects to the memory server, which sends its instructions together with your core rules/.
  2. Claude calls memory_search("sarah"). The server pulls the latest notes from GitHub, then searches them.
  3. It finds people/sarah-chen.md and calls memory_append to add the birthday.
  4. The server writes the file, then commits and pushes it to mbodag/memory. You can see the change on GitHub.
  5. Next week, in a new chat on any device, Claude searches, reads the note, and answers.
